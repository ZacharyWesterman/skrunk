If the input to this field is a 10 or 13 digit number, then it's assumed to be an ISBN. 10-digit ISBNs may also end with an X instead of a number.
Otherwise, keywords are searched for the most likely matches. These keywords may be found in any of the Author, Title, Sub-title, Category, or Description fields.
Note that:
  • When searching by keyword, books are always sorted by best keyword match first, regardless of any other sorting!
  • By default, keywords search is fuzzy, that is, it will also return close matches to the search term. E.g. searching for examples may also return items that just contain the text example. If you want to search for books that only contain the exact search term, you can enclose the search term in quotes, e.g. "examples".
