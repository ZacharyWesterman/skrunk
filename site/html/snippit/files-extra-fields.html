Extra (non-tag) fields can also be queried by using a colon : operator between values. On this screen, you may use the following fields:
  • name - searches the file name, not including the file extension. So for example, name: image would match all files whose name is "image", that is, files like image.jpg would be selected by this.
  • ext - searches the file extension. So for example, ext: .jpg would match all files with the ".jpg" extension, that is, files like image.jpg would be selected by this.
  • ephemeral - searches by ephemeral status. This field only supports the values true, false, 1, or 0; no complex filtering is allowed. So for example, ephemeral: true would match only files that are ephemeral.
